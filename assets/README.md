# Official logo goes here

Drop the official **Creative Team Production** logo into this folder as:

- `logo.svg`  ← preferred (sharpest at any size)
- `logo.png`  ← fallback

It is picked up automatically:
- top-left header of all 24 slides
- the closing frame (slide 24)

Until a file exists here, the presentation shows a clean typographic wordmark
instead. No logo is ever drawn, traced, recoloured or invented by the presentation.

Recommended: transparent background, light/white or neon-green version,
around 320–800 px wide, with some breathing room around the mark.
